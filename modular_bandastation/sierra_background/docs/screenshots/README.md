# Снимки интерфейса предыстории

Снимки сделаны локально 27 октября 2026 года при проверке этого изменения:

- `background-main.png` — компактный основной экран.
- `background-picker.png` — окно выбора с деревом подразделений и описанием.

На снимках настоящий компонент `BackgroundPage` с production CSS проекта,
запущенный в браузерном стенде на тестовой анкете. Игровые сохранения и личные
данные игроков не использовались. Это снимки стенда, а не DreamSeeker.

Изображения подготовлены в рамках этой работы и предоставлены вместе с ней
на условиях лицензии репозитория. Оформление и значки взяты из существующих
TGUI и Font Awesome проекта; сведения об их исходных лицензиях сохраняются
в соответствующих каталогах. Сторонние иллюстрации не добавлялись.
